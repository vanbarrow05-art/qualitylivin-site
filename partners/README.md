# Partner program: start here

Provider recruitment plus the customer intake flow for commercial cleaning walkthroughs.

| File | Use it for |
|---|---|
| `01-offer-and-packages.md` | The offer ladder (3 free leads → Referral 10% → $400 / $800 / $1,600), who qualifies as "5-star", unit math, what we never say |
| `02-call-scripts.md` | Scripts: local owners, national/franchise brands, gatekeeper, voicemail, email, texts, upgrade call, objection handling |
| `03-prospecting-and-listing.md` | How to use the prospect list, build lists for new cities, add partners to the website map, connect their booking calendars |
| `04-pipeline-and-training.md` | GHL pipeline stages + automations, lead delivery flow, daily routine + KPIs, 5-day caller training, compliance |
| `05-partner-agreement-outline.md` | One-page agreement outline for an attorney to finalize |
| `06-launch-promo.md` | Founding Partner offer (ties to the Jan 2027 print issue) + customer launch offer |
| `07-cleaning-walkthrough-intake.md` | Customer cleaning form, location/in-house-cleaner/legal-name/manager questions and submission to the existing GHL janitorial pipeline |
| `08-complete-sales-playbook.txt` | Current complete customer/provider call scripts, 48 rebuttals, freebies, package scopes and commission answers |
| `prospects-research.csv` | 41 researched prospects (national brands, marketplaces, TLG, Cache Valley cleaners and contractors), checked Oct 23, 2026 |

Related: `data/providers.csv` (what the website map shows), `magazine/PRINT-LAUNCH-PLAN.md`, `prompts/CLAUDE-WEBSITE-PROMPTS.md`.

**Current caller handoff:** use `08-complete-sales-playbook.txt` for the full scripts, rebuttals, freebies and package wording. It incorporates the owner's in-person-estimate and existing-janitorial-pipeline instructions.

**Calling a business that needs cleaning?** Use Script I in `02-call-scripts.md` and the intake specification in `07`. Check the prospect website, collect the details and manager's preferred visit windows, then submit the existing cleaning form. It routes to the Quality Living janitorial pipeline; the team confirms the appointment. The free-lead/provider-package scripts serve a different audience.

**First week, in order:**
1. Call TLG: get written consent → set them to `joined` on the map.
2. Call the 6 fully-qualified Cache Valley cleaners in `prospects-research.csv`.
3. Build the GHL pipeline + lead-delivery workflow (`04`).
4. Get printer quotes (`magazine/PRINT-LAUNCH-PLAN.md`) so the Founding Partner print feature is real.
